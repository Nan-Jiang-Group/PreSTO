# `data/`

Benchmark datasets and shared evaluation utilities used by the experiment scripts.

## Datasets

- `AIME.json` — AIME 2024–2025 competition problems.
- `MATH500.json` — MATH-500 evaluation set.
- `MBPP.jsonl` — Mostly Basic Python Problems code-generation benchmark.
- `human-eval-v2-20210705.jsonl` — HumanEval code-generation benchmark.
- `sample_math.jsonl` — Small sample of math problems for quick testing.
